RustCrawl API Reference

RustCrawl is a high-performance web-to-data engine built in Rust.

Getting Started

You can run RustCrawl as a standalone CLI or as an HTTP daemon.

API Endpoints

POST /v1/scrape

Accepts a JSON payload requesting page scraping and transformation.

{
  "url": "https://example.com",
  "formats": ["markdown", "links"]
}
